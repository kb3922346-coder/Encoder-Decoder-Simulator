ENCODER & DECODER - INTERACTIVE DIGITAL LOGIC SIMULATOR

HOW TO RUN
Method 1 (Local Web Server):
- Double-click start_server.bat
  This will start the local server and automatically open:
  http://localhost:8080/

Method 2 (Direct File):
- Double-click index.html (or right-click > Open with > Chrome / Edge / Firefox).

PROJECT FEATURES
- 4-to-2 binary encoder simulation (I0-I3 inputs -> A1 A0 binary output).
- 2-to-4 binary decoder simulation (A1 A0 binary switches -> Y0-Y3 outputs).
- Interactive truth tables (click any row to test).
- Theme toggle (Light/Dark mode with saved preferences).
- Clean, focused, responsive design.

TECHNOLOGIES
- HTML5, CSS3, JavaScript (Vanilla - zero dependencies required).
