⚡ What is an Encoder?

Compresses 2ⁿ inputs into n binary outputs. Here, 4 input lines are encoded into 2 binary bits. Used in computer keyboards and data transmission.

💡 What is a Decoder?

Expands n binary inputs into 2ⁿ outputs. Here, 2 binary bits activate 1 of 4 output lines. Used in memory address decoding and display drivers.
